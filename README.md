# Bondfolio Project

## Popis projektu
Bondfolio je moderní webová aplikace pro správu a investování do dluhopisů, postavená na Next.js a Supabase.

## Klíčové vlastnosti
- Správa investičního portfolia
- Vyhledávání a filtrování dluhopisů
- Analýza výnosů a rizik
- Podpora pro více jazyků
- Autentizace a autorizace uživatelů

## Instalace a spuštění

```bash
# Instalace závislostí
npm install

# Spuštění vývojového serveru
npm run dev

# Sestavení produkční verze
npm run build

# Spuštění testů
npm run test
```
